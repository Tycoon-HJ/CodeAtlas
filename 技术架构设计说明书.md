# 1. 项目定位

CodeAtlas Studio 是一个统一 AI Coding Agent 工作台。

支持：

* Claude Code
* Codex CLI
* Gemini CLI
* Qwen-Code
* OpenCode

等 Agent 的统一接入。

---

# 2. 技术架构

整体采用：

Tauri + Vue3 + Rust + SQLite

架构如下：

┌─────────────────────────┐
│ Vue3 UI Layer           │
└──────────┬──────────────┘
│ IPC
┌──────────▼──────────────┐
│ Runtime Layer (Rust)    │
└──────────┬──────────────┘
│
┌──────────▼──────────────┐
│ Capability Center       │
└──────────┬──────────────┘
│
┌──────────▼──────────────┐
│ Provider Adapter        │
└──────────┬──────────────┘
│
Claude / Codex / Gemini
